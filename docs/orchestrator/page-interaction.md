# 页面交互说明

> **定位**：定义全平台页面的布局、交互行为、状态覆盖。是前端实现的规格依据，也是 QA Agent 验收的参照。

---

## 一、全局统一规范

### 1.1 布局骨架

```
┌──────┬──────────────────────────────────────────┐
│      │ Logo           🔍搜索框        🔔通知 头像 │ ← Header 56px
│      ├──────────────────────────────────────────┤
│ 侧边栏 │                                          │
│240px  │          内容区                            │
│(折叠  │      padding: 24px                        │
│ 72px) │      max-width: 1920px                    │
│      │                                          │
└──────┴──────────────────────────────────────────┘
```

### 1.2 侧边栏

| 设计点 | 说明 |
|--------|------|
| 展开宽度 | 240px |
| 折叠宽度 | 72px（仅图标） |
| 折叠方式 | 汉堡菜单按钮，200ms 过渡动画 |
| 菜单项 | 首页 / 分区(展开子菜单) / 排行 / 关注 / 历史 / 稍后再看 / 喜欢 |
| 激活态 | 激活项背景 `rgba(255,255,255,0.1)`，左侧 3px 主色竖线 |
| 图标 | 20px，和文字间距 12px |
| 分区子菜单 | 可展开/折叠，默认收起，激活时展开 |

### 1.3 顶栏

| 设计点 | 说明 |
|--------|------|
| 高度 | 56px |
| 搜索框 | 居中，宽度 600px(max)，圆角药丸(50px)，搜索图标在左侧 |
| 通知图标 | 铃铛，有未读时右上角红色圆点(8px) |
| 用户头像 | 32px 正圆，点击弹出下拉菜单(个人空间/创作中心/设置/退出) |

### 1.4 视频卡片（全平台通用）

```
┌──────────────┐
│              │
│  封面 16:9    │ ← 圆角 12px，hover 放大 1.02
│              │
│   ▶ 12:34   │ ← 时长标签，右下角，黑底白字 12px，圆角 4px
└──────────────┘
┌──┐
│头│ UP 主名      ← 头像 24px 正圆 + 昵称 13px
└──┘
标题 (两行，超出省略)  ← 14px/500，#fff
UP主 · 12.3K播放 · 3天前 ← 12px/400，#aaa
```

| 交互 | 说明 |
|------|------|
| 点击封面/标题 | 跳转 `/video/[id]` |
| 悬停 >1s | 播放 3s 预览片段（静音），移出停止，200ms ease |
| 点击 UP 主头像/名称 | 跳转 `/user/[id]` |

## 二、视频详情页 `/video/[id]`

### 2.1 整体布局

```
┌──────┬──────────────────────────────────┬──────────┐
│      │                                  │          │
│ 侧边栏 │        视频播放器 16:9            │ 推荐列表   │
│      │        + 弹幕层叠加                │ (300px)  │
│      │                                  │          │
│      ├──────────────────────────────────┤ 竖向排列   │
│      │ 视频标题                          │ 7-8个     │
│      │                                  │ 视频卡片   │
│      │ UP主行 + 关注按钮                  │          │
│      │ 播放量 · 发布时间                  │ 独立滚动   │
│      │                                  │          │
│      │ [👍] [🪙] [⭐] [↗分享]            │          │
│      │                                  │          │
│      │ 简介区（折叠/展开）                  │          │
│      │                                  │          │
│      │ 💬 评论 (N)                        │          │
│      │ 评论输入框                         │          │
│      │ 评论列表（楼中楼）                   │          │
└──────┴──────────────────────────────────┴──────────┘
```

### 2.2 播放器 + 弹幕层

| 设计点 | 说明 |
|--------|------|
| 播放器 | 16:9，圆角 12px，占内容区 ~68% 宽度 |
| 弹幕层 | 绝对定位覆盖播放器，`pointer-events: none` |
| 弹幕文本 | 白色描边黑字 16px，阴影抗锯齿 |
| 弹幕发送框 | 播放器底部内侧，半透明黑底 `rgba(0,0,0,0.6)` + 输入框(圆角50px) + 发送按钮(药丸) + 颜色圆点(6色) + 位置选择 |
| 弹幕开关 | 控制栏右下，`弹幕 ON/OFF` 开关 |
| 控制栏 | 透明悬浮，鼠标移入 200ms 淡入显示（播放/暂停/进度条/音量/全屏/清晰度/弹幕开关） |

### 2.3 视频信息区

| 区块 | 设计点 |
|------|--------|
| 标题 | 18px/700，#fff，不截断最多两行 |
| UP主行 | 头像 36px正圆 + 昵称 14px/500 + 关注按钮(药丸 outline→filled) |
| 辅助信息 | 播放量+发布时间，12px，#aaa |
| 三连按钮 | 横排，图标 20px + 数字 14px，间距 16px，hover 放大 1.05 |
| 点赞 | 已点赞：图标填充 `--color-primary`，数字加粗；未点赞：图标 outline |
| 投币 | 已投币：图标填充 `--color-gold`；点击弹出投币数选择(1或2枚) |
| 收藏 | 已收藏：图标填充 `--color-gold`；点击弹出收藏夹选择弹窗 |
| 分享 | 点击弹出分享面板(复制链接 + 社交平台图标按钮) |

### 2.4 简介区

| 设计点 | 说明 |
|--------|------|
| 折叠状态 | 默认 2 行 + "...展开"，12px/400，#aaa |
| 展开状态 | 完整 description + 底部标签列表 + "...收起" |
| 标签 | 小药丸(8px圆角)，`#标签名`，hover 变主色，点击跳 `/search?tag=xxx` |
| 动画 | max-height 300ms ease |

### 2.5 评论区

| 设计点 | 说明 |
|--------|------|
| 排序 | "按热度" / "按时间" Tab |
| 评论框 | 头像 32px正圆 + textarea(圆角8px，自动增高) + 发送按钮(药丸) |
| 一级评论 | 头像 32px + 昵称 + 时间(12px,#aaa) + 内容 + 👍数字 + 回复按钮 |
| 楼中楼 | 左边框 2px(#333)，缩进 40px，默认展开 3 条 + "展开更多回复(N条)" |
| 加载更多 | IntersectionObserver 触底加载 |

### 2.6 右侧推荐列表

| 设计点 | 说明 |
|--------|------|
| 宽度 | 300px，固定 |
| 单项 | 缩略图 168×94(16:9) + 标题(两行 13px) + UP主(12px) + 播放量·时长(12px,#aaa) |
| 间距 | 项间距 8px |
| 滚动 | `overflow-y: auto`，独立于左侧页面滚动 |
| 悬停预览 | 和首页 VideoCard 共用逻辑 |

### 2.7 状态覆盖

| 状态 | 处理 |
|------|------|
| 视频不存在(id 无效) | ErrorState: "视频不存在或已被删除" |
| 视频转码中 | 播放器区域半透明遮罩 + "转码中，预计 X 分钟" + 进度百分比 |
| 视频下架(banned) | ErrorState: "该视频已被下架" |
| 已登录看自己的视频 | UP主行不显示"关注"，显示"编辑视频"按钮 |
| 未登录点三连 | Toast: "请先登录"，200ms 后自动跳转 `/login` |
| 弹幕断连 | Toast: "弹幕已断开，正在重连..."，danmakuStore.isConnected = false |
| 弹幕重连成功 | Toast: "弹幕已恢复" |
| 评论加载失败 | ErrorMessage + 重试按钮 |

## 三、侧边栏+内容页面

### 3.1 首页 `/`

```
┌──────┬──────────────────────────────────────────┐
│      │                                          │
│ 侧边栏 │  推荐 ──────────────────────────────→    │
│      │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│      │  │ 卡片  │ │ 卡片  │ │ 卡片  │ │ 卡片  │ → │ ← 横向滚动
│      │  └──────┘ └──────┘ └──────┘ └──────┘   │
│      │                                          │
│      │  热门 ──────────────────────────────→    │
│      │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│      │  │ ...  │ │ ...  │ │ ...  │ │ ...  │ → │
│      │  └──────┘ └──────┘ └──────┘ └──────┘   │
│      │                                          │
│      │  游戏区 ────────────────────────────→    │
│      │  ┌──────┐ ┌──────┐ ...                   │
│      │  └──────┘ └──────┘                       │
│      │                                          │
│      │  ... 无限滚动（横向分组）                   │
```

| 设计点 | 说明 |
|--------|------|
| 分组标题 | "推荐" "音乐" "游戏区" ...，18px/700 + "查看全部"链接 |
| 行内滚动 | `overflow-x: auto`，`scroll-snap-type: x`，隐藏滚动条(thin) |
| 行左右箭头 | hover 行时显示左右箭头按钮，点击滚动一屏 |
| 无线滚动 | IntersectionObserver 监听底部，加载更多分组 |
| 空状态 | 不适用（总有推荐数据） |
| 加载 | 行内骨架屏：4 个卡片占位(shimmer 动画) |

### 3.2 排行榜 `/ranking`

| 设计点 | 说明 |
|--------|------|
| 顶部Tab | 日榜 / 周榜 / 总榜，默认周榜 |
| 分区筛选 | Tab 下方下拉或小标签，默认全部 |
| 列表 | 纵向排列，每行：排名数字(前3名金色/银色/铜色) + 视频卡片(横向布局，不带头像) + 播放量 |
| 空状态 | EmptyState: "暂无排行数据" |
| 加载 | 列表骨架屏 |

### 3.3 关注页 `/following`

| 设计点 | 说明 |
|--------|------|
| 列表 | 关注UP主的新视频 Feed，时间倒序 |
| 卡片 | 标准视频卡片 |
| 空状态 | EmptyState: "你还没有关注任何UP主" + "去发现"按钮 → 首页 |
| 加载 | 卡片骨架屏 |

### 3.4 历史 `/history`

| 设计点 | 说明 |
|--------|------|
| 列表 | 视频卡片网格，按最近观看时间倒序 |
| 进度条 | 卡片封面下方细进度条(2px高，主色)，已看30%则填充30%宽 |
| 续播按钮 | hover 卡片时封面中央出现播放图标 + "继续观看"文字 |
| 批量操作 | 顶栏"清除全部历史"按钮(二次确认弹窗) |
| 空状态 | EmptyState: "暂无观看历史" |
| 加载 | 卡片骨架屏 |

### 3.5 稍后再看 `/watch-later`、喜欢 `/liked`

| 稍后再看 | "暂无稍后再看视频" |
| 喜欢 | "你还没有喜欢的视频" + "去首页看看" |

## 四、表单与操作页

### 4.1 上传页 `/upload`

| 设计点 | 说明 |
|--------|------|
| 步骤指示器 | 顶部三步进度条：选择文件 → 填写信息 → 发布 |
| 步骤1: 拖拽区 | 虚线边框区域 400×225(16:9)，支持拖拽/点击选择，显示文件名校验格式和大小 |
| 步骤2: 表单 | 标题(textarea,1-80字) + 描述(textarea,≤2000字) + 分类(级联选择器) + 标签(多选输入) + 封面(自动截取预览+手动上传) |
| 步骤3: 发布 | 预览卡片 + "立即发布"/"存入草稿箱" 两个按钮 |
| 步骤间切换 | 点击上一步可回退 |
| 状态覆盖 | 文件过大→Toast"文件不能超过500MB"、格式不支持→Toast"仅支持mp4/avi/mkv"、发布成功→跳转视频详情页、存草稿→跳转草稿箱 |

### 4.2 草稿箱 `/drafts`

| 设计点 | 说明 |
|--------|------|
| 列表 | 标准视频卡片网格 + 状态标签"草稿" |
| 操作 | 每个卡片hover出现"继续编辑"/"删除"按钮 |
| 空状态 | EmptyState: "草稿箱为空" |
| 加载 | 卡片骨架屏 |

### 4.3 视频管理 `/manage`

| 设计点 | 说明 |
|--------|------|
| 布局 | 和用户空间共用，Tab"投稿"即为管理页 |
| 表格视图 | 缩略图(120×68) + 标题 + 状态标签 + 播放量 + 时间 + 编辑/删除按钮 |
| 状态标签 | 草稿(灰) / 已发布(绿) / 转码中(蓝) / 已下架(红) |
| 编辑 | 弹出编辑弹窗(修改标题/描述/标签/分类)，不走上传流程 |
| 删除 | 二次确认弹窗 |
| 空状态 | EmptyState: "还没有投稿" + "去上传"按钮 |

## 七、认证页

### 7.1 登录 `/login`、注册 `/register`

| 设计点 | 说明 |
|--------|------|
| 布局 | `auth.vue`，居中卡片(400×auto)，无侧边栏无顶栏 |
| 卡片 | 圆角 12px，padding 32px，背景 `--color-surface` |
| Logo | 卡片顶部，居中 |
| 登录表单 | 用户名/邮箱 input + 密码 input(可切换明文) + 登录按钮 + 注册链接 |
| 注册表单 | 用户名 + 邮箱 + 密码 + 确认密码 input + 注册按钮 + 登录链接 |
| 验证 | 前端格式校验(用户名3-20位/密码6-30位/邮箱格式)，错误提示在 input 下方红色 12px |
| 状态 | 提交中按钮 loading + 禁用；错误Toast显示后端返回的错误信息；成功跳转首页或 redirect 参数页面 |

## 八、通用交互规范

### 8.1 状态组件

| 组件 | 使用场景 | 视觉 |
|------|---------|------|
| LoadingSpinner | 页面初始加载 | 居中旋转动画，36px |
| Skeleton | 列表/卡片加载中 | shimmer 动画，灰色占位块，匹配目标形状 |
| EmptyState | 列表无数据 | 图标(64px) + 提示文字 + 可选操作按钮 |
| ErrorMessage | 数据加载失败 | 红色图标 + 错误信息 + "重试"按钮 |
| Toast | 操作反馈 | 右上角弹出(从右滑入)，3s 自动消失，支持 success/error/info/warning |

### 8.2 路由过渡

## 模板

人新增需求时复制以下格式：

```markdown
| 2026-07-04 | {需求描述} | 新增功能 / 修改现有 / 问题反馈 | 建议归属阶段N |
```

**类型说明**：
- **新增功能**：现有 5 阶段未覆盖的功能组件
- **修改现有**：对已规划的功能进行调整
- **问题反馈**：实施过程中发现的需求层面问题
- **新增 Skill**：Agent 发现缺少完成工作所需的 Skill/权限

**主 Agent 处理流程**：
1. 读 `docs/orchestrator/backlog.md`
2. 分析需求的影响范围（涉及哪些包、哪些阶段）
3. 将需求拆分为可执行的任务
4. 判断是追加到现有阶段需求 md，还是创建新的子需求文件
5. 更新对应阶段的需求 md 或 `docs/orchestrator/feature-list.md`
6. 移动本条到 `## 已处理`，标注处理结果
